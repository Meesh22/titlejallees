# موقع نادي جليس القرائي - منطقة القصيم
> لأن القراءة تجمعنا

موقع إلكتروني عربي متكامل، عصري، متجاوب (Responsive)، ومصمم خصيصاً لنادي «جليس القرائي» في منطقة القصيم بالمملكة العربية السعودية، باستخدام التقنيات الأساسية القياسية الصرفة فقط: **HTML5 + CSS3 + Pure JavaScript** (بدون أي أطر عمل أو مكتبات خارجية).

---

## 📁 هيكلية ملفات المشروع

```text
jaleespr/
├── index.html                   # هيكل الصفحة الرئيسي وجميع الأقسام الدلالية
├── style.css                    # التصميم والهوية البصرية الكاملة بنظام RTL
├── script.js                    # المنطق البرمجي، عرض البيانات، النماذج، والتفاعلات
├── README.md                    # دليل تشغيل وتخصيص الموقع
└── assets/
    └── images/
        ├── logo.svg             # شعار النادي النصي مع رمز الكتاب المفتوح
        ├── hero-illustration.svg# رسمة بيئة القراءة والمكتبة الثقافية
        ├── meeting-1.svg        # غلاف اللقاء المسجل الأول (نمط يوتيوب)
        ├── meeting-2.svg        # غلاف اللقاء المسجل الثاني
        ├── meeting-3.svg        # غلاف اللقاء المسجل الثالث
        ├── upcoming-1.svg       # غلاف اللقاء القادم
        └── avatar-placeholder.svg # صورة افتراضية لأعضاء النادي
```

---

## 🚀 طريقة تشغيل الموقع محلياً

1. افتح مجلد المشروع `jaleespr`.
2. انقر نقراً مزدوجاً على ملف **`index.html`** وسيفتح مباشرة في متصفحك (Chrome، Edge، Safari، إلخ).
3. أو يمكنك تشغيل خادم محلي خفيف عبر الامتداد **Live Server** في محرر الأكواد.

---

## 🎨 طريقة تعديل واستبدال الشعار والصور

* **شعار النادي:** استبدل الملف الموجود في المسار `assets/images/logo.svg` بشعار النادي الرسمي بصيغة PNG أو SVG محتفظاً بالاسم نفسه، أو عدل مساره في ملف `index.html`.
* **صورة الواجهة الرئيسية (Hero):** استبدل `assets/images/hero-illustration.svg` بصورة ملتقطة من أحد لقاءات النادي الفعلية.
* **أغلفة اللقاءات:** ضع صور لقاءاتكم داخل مجلد `assets/images/` واكتب أسماءها في ملف `script.js`.

---

## 📝 كيفية إضافة وتعديل اللقاءات والأعضاء (في ملف `script.js`)

جميع بيانات الموقع مفصولة في أعلى ملف **`script.js`** ضمن مصفوفات واضحة جداً:

### 1. إضافة لقاء مسجل جديد:
أضف عنصراً جديداً داخل مصفوفة `recordedMeetings`:
```javascript
{
  id: 4,
  title: "عنوان اللقاء الجديد",
  description: "نبذة عن موضوع النقاش والكتب المطروحة...",
  thumbnail: "assets/images/اسم_الصورة.jpg",
  guest: "اسم الضيف الكريم",
  date: "١٤٤٦/٠١/١٠ هـ",
  youtubeUrl: "https://www.youtube.com/watch?v=رابط_الفيديو" // اتركه فارغاً "" إذا لم يُرفع بعد
}
```

### 2. إضافة لقاء قادم:
أضف عنصراً جديداً في مصفوفة `upcomingMeetings`:
```javascript
{
  id: 102,
  title: "عنوان الفعالية القادمة",
  description: "وصف الجلسة وأهدافها...",
  cover: "assets/images/اسم_الغلاف.jpg",
  guest: "اسم الضيف",
  date: "الخميس ١٥ شعبان",
  time: "٨:٣٠ مساءً",
  location: "مقر النادي - بريدة",
  status: "التسجيل مفتوح",
  actionUrl: "https://forms.gle/UZY6DnS9W2X5ft9w8",
  actionText: "حجز مقعد"
}
```

### 3. إضافة أو تعديل الأعضاء:
عدل مصفوفة `clubMembers`:
```javascript
{
  id: 4,
  name: "اسم العضو",
  role: "عضو فاعل / قارئ",
  bio: "نبذة واهتمامات العضو الثقافية...",
  avatar: "assets/images/avatar-placeholder.svg",
  interests: ["الرواية", "التاريخ", "الفكر"]
}
```

## 🔗 ربط نموذج الانضمام بخدمة استقبال حقيقية (API)

* الموقع مضبوط افتراضياً ليتعامل بصدق وشفافية تامة: يتحقق من صحة الاسم ورقم الهاتف السعودي، ويوضح للزائر أن النموذج غير متصل بخادم ويوجهه مباشرة لرابط استبيان Google Forms الرسمي.
* **لربطه باستقبال فعلي:**
  1. افتح ملف `script.js`.
  2. في السطر الأول، ضع رابط خدمة الاستقبال (مثل Formspree أو Google Apps Script Webhook):
     ```javascript
     const FORM_ENDPOINT = "https://formspree.io/f/your_form_id";
     ```
  3. بمجرد وضع الرابط، سيقوم النموذج تلقائياً بإرسال بيانات الاسم ورقم الهاتف وتاريخ الطلب كطلب `POST JSON` وعرض رسالة نجاح حقيقية.

## 🎯 المزايا التقنية المنفذة
- كود قياسي صرف 100% بدون أي مكتبة خارجية.
- توافق كامل وتجاوب تام مع كافة الشاشات (الهواتف، الأجهزة اللوحية، الكمبيوتر).
- قائمة جوال منسدلة مع حماية الوصول وتوافق لوحة المفاتيح (Esc / Focus Trap).
- مشغل فيديو مدمج للقاءات اليوتيوب داخل نافذة منبثقة (Modal) مع مراعاة الحالات التي لا يتوفر فيها رابط.
- تحقق فوري ودقيق من أرقام الجوال السعودية (صيغ `05`, `9665`, `+9665`).
- حركات ظهور وتمرير سلسة متوافقة مع إعدادات تفضيل تقليل الحركة (`prefers-reduced-motion`).
- زر عودة للأعلى ذكي يظهر تلقائياً عند التمرير.
