# جليس | مساحة الأعضاء

موقع أعضاء نادي جليس القرائي — مشروع مستقل تمامًا عن الموقع التعريفي القديم.

## هيكل المشروع

```text
├── index.html      # بوابة الأعضاء والتطبيق كاملًا (هو صفحة البداية)
├── app.css         # هوية النادي وتصميم التطبيق (RTL)
├── app.js          # قائمة الأعضاء، الدخول، الشاشات، والتفاعلات
├── logo-light.png  # الشعار على خلفيات فاتحة (هوية الموقع)
├── logo-dark.png   # الشعار على خلفيات داكنة
├── logo-icon.png   # أيقونة الموقع (favicon)
├── serve.ps1       # خادم محلي بسيط للتجربة
└── jalees-announcement.png
```

## التشغيل

- افتح `index.html` مباشرة في المتصفح، أو
- شغّل `serve.ps1` ثم افتح `http://localhost:8765/`.

## العضوية والدخول

- العضوية **بالاسم فقط**: اكتب اسمك كما هو مسجل في قائمة أعضاء النادي (٦٣ عضوًا).
- لا يوجد رمز عضوية، ويقبل النظام الاختلافات البسيطة في الهمزات والمسافات (مثل «عبد الرحمن» و«عبدالرحمن»).
- بعد الدخول يبقى اسمك محفوظًا في هذا الجهاز حتى تسجّل الخروج.

## حفظ التقدم

- كل عضو له سجل مستقل في المتصفح، ويُحفظ تلقائيًا بعد كل قراءة أو تعديل.
- سجل القراءات، مكتبتي، الاقتباسات، المقالات، والهدف الأسبوعي كلها خاصة بكل اسم.
- مفاتيح التخزين: `jalees-session-v2` للجلسة، و`jalees-member-v2:<id>` لكل عضو.

## روابط مفيدة للتطوير

- لتجاوز البوابة أثناء التطوير: `index.html?demo=1` (يفتح باسم مشعل الحفير).
- لعضو محدد: `index.html?demo=1&member=خالد%20الواصل`
- لفتح شاشة محددة: `index.html?demo=1&screen=readings`
  (الشاشات: `home`, `readings`, `quotes`, `library`, `articles`, `profile`)
