# جليس | مساحة الأعضاء

موقع أعضاء نادي جليس القرائي — مشروع مستقل تمامًا عن الموقع التعريفي القديم.

## هيكل المشروع

```text
├── index.html      # بوابة الأعضاء والتطبيق كاملًا (هو صفحة البداية)
├── app.css         # هوية النادي وتصميم التطبيق (RTL)
├── app.js          # البيانات، الدخول، الشاشات، والتفاعلات
├── logo.png        # أيقونة الموقع (favicon)
├── serve.ps1       # خادم محلي بسيط للتجربة
└── jalees-announcement.png
```

## التشغيل

- افتح `index.html` مباشرة في المتصفح، أو
- شغّل `serve.ps1` ثم افتح `http://localhost:8765/`.

## الدخول والتجربة

- رمز العضوية التجريبي: `JALEES` (أو زر الدخول السريع).
- لتجاوز البوابة أثناء التطوير: `index.html?demo=1`
- لفتح شاشة محددة: `index.html?demo=1&screen=readings`
  (الشاشات: `home`, `readings`, `quotes`, `library`, `articles`)
