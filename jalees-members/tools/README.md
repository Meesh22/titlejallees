# دليل إدخال بيانات الأعضاء (Google Sheet)

الملف `GoogleSheet_AppsScript.gs` جاهز للّصق في Google Sheet، ويقوم بثلاثة أشياء:
يجهّز الشيت، يصدّر نسخة احتياطية، ويدفع البيانات إلى GitHub مباشرة.

## ١) تجهيز الشيت

1. أنشئ Google Sheet جديداً.
2. من القائمة: **Extensions ← Apps Script**.
3. احذف المحتوى الموجود، والصق كامل ملف `GoogleSheet_AppsScript.gs`، ثم احفظ 💾.
4. من أعلى محرر Apps Script شغّل الدالة `setupSheet` ووافق على الصلاحيات.
5. أعد تحميل صفحة الشيت → تظهر قائمة جديدة: **جليس | أدوات المحتوى**.

> `setupSheet` يكتب لائحة الأعضاء الـ ٧٠ تلقائياً في تبويب «الأعضاء»، ولا يمسح
> أي بيانات أدخلتها في التبويبات الأخرى.

## ٢) إدخال البيانات

| التبويب | الأعمدة |
|---------|---------|
| الاقتباسات | العضو · الاقتباس · الكتاب/المصدر · التاريخ |
| المقالات | العضو · عنوان المقال · مقتطف · التاريخ · الرابط |
| الملخصات | العضو · الكتاب · المؤلف · الملخص · التاريخ |

- عمود «العضو» **قائمة منسدلة** بأسماء الـ ٧٠ — اختر منه فقط.
- اترك أي حقل غير متاح فارغاً؛ الموقع يعرض «بدون مصدر» أو يخفي الحقل.
- التاريخ يُكتب كنص (مثلاً `١٤ جمادى الأولى ١٤٤٦`) حتى لا يتحول إلى رقم.

## ٣) النشر

### أ) دفع تلقائي إلى GitHub (الموصى به)

1. من قائمة **جليس | أدوات المحتوى** اختر **إعدادات GitHub** وأدخل مرة واحدة:
   - المالك: `Meshh22`
   - المستودع: `jalees-tool`
   - الفرع: `main`
   - الـ token: أنشئه من GitHub ← Settings ← Developer settings ←
     Personal access tokens ← Tokens (classic) ← Generate new token،
     وامنحه صلاحية `repo` (أو Fine-grained بصلاحية **Contents: read and write**).
2. بعد إدخال البيانات اختر **دفع إلى GitHub الآن** (أو شغّل المزامنة التلقائية أدناه).
3. يحدّث السكربت ملفات `data/content/*.json` في commit واحد، وينشر Vercel تلقائياً.

### المزامنة التلقائية (أريح خيار)

من القائمة اختر **«٤) تشغيل المزامنة التلقائية»** مرة واحدة. بعدها:
- أي تعديل في الشيت يُرسل إلى GitHub خلال **١٠ دقائق** كحد أقصى، دون أن تضغط أي زر.
- لا يُرسل شيء إذا لم تتغير البيانات (مقارنة بصمة محتوى).
- كل عملية نشر تُسجَّل في تبويب جديد **«سجل المزامنة»** (الوقت / الحالة / عدد الملفات / الملاحظة).
- لإيقافها: **«٥) إيقاف المزامنة التلقائية»**.

> لاحظ أن المزامنة تحتاج إعدادات GitHub مضبوطة (`إعدادات GitHub`) قبل تشغيلها.

### ب) نسخة احتياطية يدوية

اختر **تصدير JSON (نسخة احتياطية)**؛ سيُنشأ ملف في Google Drive يحوي كل
البيانات. يمكنك تسليمه لي أو نسخ محتواه إلى `jalees-members/data/content/`.

## شكل الملفات بعد التصدير

```
data/content/
├── index.json     # أعداد الاقتباسات/المقالات/الملخصات لكل عضو (خفيف جداً)
├── m1.json        # محتوى العضو وحده
├── m2.json
└── ...            # حتى m70.json
```

الصفحة الرئيسية تحمّل `index.json` فقط (لأرقام البطاقات)، وصفحة العضو تحمّل
ملفه وحده — لذلك تبقى الصفحات سريعة حتى مع آلاف السجلات.
